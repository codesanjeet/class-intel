# Class-Intel

Class-Intel is an AI-powered classroom and education platform built to provide intelligent learning features using modern web technologies and Generative AI.

## 🚀 Tech Stack

### Backend

* Python
* FastAPI
* PostgreSQL
* SQLAlchemy

### Frontend

* Next.js

### AI

* Google Generative AI

## ✨ Features

* AI-powered educational assistance
* Fast and scalable REST APIs using FastAPI
* PostgreSQL for persistent data storage
* Modern frontend built with Next.js
* Integration with Google Generative AI models
* Structured backend architecture

## 🛠️ Built With

`FastAPI` • `PostgreSQL` • `Next.js` • `Google GenAI` • `Python`

## 💡 About

Class-Intel was built as a hackathon project to explore how Generative AI can be integrated with modern backend and frontend technologies to create useful tools for education.
